# braces 3.0.3 项目维护修复

本项目对 GHSA-vfj7-8cjw-p6xm 使用正式包管理器补丁，组件名称和版本保持不变。官方公告仍没有正式修复版，原始安全报告中的这一条也会保留；发布检查不会把它伪装成官方已修或扫描结果为零。

## 修复与验证

根 package.json 的 patchedDependencies 与根 pnpm-lock.yaml 固定登记 frontend/patches/braces@3.0.3.patch。补丁来源与所有运行文件摘要记录在同目录完整性清单，除嵌套深度保护之外，也拒绝外部语法树中非字符串节点值、非法节点容器和循环，避免在隐式转换或展平中再次耗尽栈。

frontend/scripts/braces-check.mjs 每次直接检查真实安装的全部 braces 实例，核对包名、版本、补丁摘要、锁文件登记、所有运行文件摘要、下游实际加载路径，并执行安全及正常匹配回归。未打补丁、混入其他版本、任意摘要改变或回归失败均拒绝通过。干净安装与真实下游验证不能由临时副本的试验报告代替。

## 原安全扫描保持执行

scripts/check-dependency-audit.mjs 先在同一进程验证安装后的补丁，再执行原来的 pnpm audit --json --audit-level high，保存完整原始 JSON 和单独的验证记录，CI 始终尝试归档这两份结果。

只有唯一阻塞项同时满足以下条件，才记为项目维护补丁已处理：

- 官方公告网址精确为 GHSA-vfj7-8cjw-p6xm，包为 braces，所有受影响安装路径的版本均为 3.0.3。
- 真实安装补丁、全部实例摘要及回归检查已即时通过；不能使用自填或以前生成的通过报告。
- 高危阻塞项只有这一条，没有任何严重阻塞项，扫描正常完成且结果结构完整。
- 时间早于北京时间 2026 年 11 月 4 日零点。到期会自动拒绝此项处理，需要重新审核维护状态。

另一个高危/严重公告、公告身份或版本改变、缺失/矛盾的报告、网络故障、进程超时及未知格式均失败。现有高危阈值不变，不增加全局忽略项，不改成仅扫描生产依赖，不伪造安全版本号。

## 维护边界

深度硬上限为 100，更深的模式会明确抛错，调用者仍需按正常方式处理异常。这是本公告所涉及递归路径的有限修复，不是对任意代码对象、所有资源耗尽攻击或全部依赖安全的保证。新增官方修复版时应优先评估升级，删除过时补丁和这条局部处理，并重新验证下游兼容性。

本次维护方案在用户先前授权发布、看到剩余阻塞及具体补丁方案后明确要求“立即修复”的范围内执行。它不扩大已批准的界面、产品能力或内容公开范围。
