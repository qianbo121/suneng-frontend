每个候选组合同时保存通用设备分类资料和具体应用对应资料；设备厂家资料只支持工件、工艺与设备类型的应用对应，不支持未核实的温度、时间、转移秒数、装载上限，也不代表苏能制造或供货能力。

本批登记并复核的主要官方资料：

- 美国能源部第三版《Improving Process Heating System Performance》：只作为通用设备分类资料。
- Surface Combustion台车式炉应用资料：支持大型、重载工件的周期式台车炉应用边界。
- Tenova LOI中厚板热处理资料：支持板材连续热处理线及其加热、淬火、回火系统边界。
- Tenova管棒辊底炉资料：支持钢管等长材的辊底式连续热处理应用。
- EBNER钢带卷与钢丝卷罩式退火资料：分别支持卷材和盘卷线材的罩式周期处理应用。
- AFC-Holcroft网带连续炉资料：支持紧固件等小件批量连续调质应用。

与长材连续调质对应的第7条设备应用资料仍为`unverified`，没有进入本次候选包。
