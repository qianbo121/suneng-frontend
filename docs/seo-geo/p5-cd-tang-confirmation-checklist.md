### Q1 炉衬局部修复、扩大拆检与整体处理

当前边界：

- 2020 台车炉电改燃方案只确认该项目采用“保持原有结构，将损坏部分纤维成块清除更换”的方案设计；
- 该文件不能证明所有项目都适合局部修复，也不能单独形成通用否决标准；
- 炉顶下沉、鼓包，冷面钢板异常升温或变色，贯通裂缝，锚固件明显腐蚀减薄，以及超温、进水、气氛异常等，可先作为需要扩大检查的高风险信号，是否必须整体处理仍需结合开衬检查结果。

请唐工确认：

1. “损坏范围小、未贯穿冷面、损坏区外锚固完好、失效原因局部、新旧衬可以可靠衔接”能否作为考虑局部修复的基本条件？需要删改哪一条？
2. 哪些现象出现后应扩大拆检，哪些现象可以直接判定整面或整体处理？
3. 改燃料、提高温度、增加装炉量等工况变化时，是否必须重新核算炉衬、炉压和气流条件？
4. 哪些判断可以公开成采购指南，哪些只能在停炉检查后给结论？

记录：

- 确认结论：判断轴不是单看热面损坏面积，而是炉衬支撑体系、冷面状态、锚固连续性和失效原因是否仍可控。损坏不连片、未及冷面、损坏区外锚固完好、失效原因为局部且新旧衬可以可靠衔接时，可考虑局部修复。
- 扩大拆检信号：炉顶下沉或鼓包、锚固件大面积腐蚀减薄、冷面钢板异常升温或变色、裂缝贯通、长期超温或气氛侵蚀、多次补丁互相搭接，以及超温、进水等异常历史。
- 需要调取的图纸或检查记录：炉衬结构图、锚固布置图、冷面测温记录、超温/进水记录和开衬检查照片。
- 适用条件：现有工况不变，损坏范围和原因可通过停炉检查确认。
- 不适用条件：改燃料、提高温度、增加装炉量或改变炉压/气流组织时，必须重新核算，不能直接沿用旧炉衬结论。
- 可公开完整句：炉衬是否局部修复，不能只看热面损坏面积；应同时检查冷面钢板、锚固体系、失效原因和新旧衬接缝条件。出现炉顶下沉、冷面异常升温或贯通裂缝等信号时，应扩大拆检，最终范围以停炉检查为准。

- 尚未找到对应产品合格证、供应商样本、施工记录或验收文件，不能推断 `1140 型`的准确温度等级，也不能把 `≥40%`写成苏能所有炉型的通用标准。

请唐工确认：

2. `压缩量≥40%`的计算基准是什么：模块制造压缩量、安装压缩量，还是接缝方向的压缩要求？
3. 该参数适用于哪些材料、部位和安装方式？哪些情况下不能复用？
4. 在取得供应商资料或施工记录前，页面是否仅写“模块牌号和安装压缩要求按材料体系与施工方案确认”？

记录：

- 确认结论：`1140 型`和`压缩量≥40%`只能确认是 2018 项目技术方案载明的材料型号/规格与方案参数。`1140 型`的准确含义需查供应商产品资料；`≥40%`反映纤维模块通过预压缩补偿高温收缩、维持接缝压紧的设计意图，但不能脱离材料、模块结构和安装方向通用化。
- 产品资料或施工记录：仍需调取鲁阳对应时期产品样本、产品合格证、施工方案和安装记录。

- 不适用条件：不得把`1140 型`直接解释为未经资料证明的分类温度；不得发布“压缩不足会在三五年后集中失效”等无项目记录支撑的时间结论。
- 可公开完整句：某项目技术方案采用`1140 型耐火纤维模块、压缩量≥40%`的设计参数；具体牌号含义和安装压缩要求，应结合产品合格证、材料体系与施工方案确认。

- 当前不能发布统一温度平台、升温速度或固定时长。

请唐工确认：

1. 烘炉要求是否应由耐材供应商提供材料边界，再由炉体设计/施工责任方结合项目条件形成最终曲线？
2. 全纤维、浇注料、可塑料/捣打料、砖砌体分别需要关注什么，哪些差异可以公开？
3. 是否应至少交付时间—温度实测曲线、保温平台实际时长、排湿口状态、排汽观察、异常中断处理和环境温湿度记录？
4. 判断水分排出完成应看哪些证据，为什么不能只用固定烘炉小时数判断？

记录：

- 确认结论：耐材供应商先提供材料干燥和升温边界，炉体设计或施工责任方再结合材料组合、施工厚度、排湿条件和炉型形成项目烘炉制度，施工方按曲线执行并留证。
- 可公开的方法：全纤维、浇注料、可塑料/捣打料、砖砌体的含水和排湿机制不同；烘炉记录至少应包含时间—温度实测曲线、保温平台实际时长、排湿口状态、排汽观察、异常中断处理和环境温湿度。
- 必须按项目确认的部分：温度平台、升温速度、保温时间以及水分排出完成的判定方法。不能把任何一条通用曲线跨材料体系复用。
- 可提供的烘炉记录样本：待从具体项目调取；当前未检出可跨项目复用的完整记录。
- 可公开完整句：烘炉曲线应由耐材体系、施工厚度、含水情况、排湿条件和炉型共同决定；验收应看实测曲线、排汽和异常记录，不能只以“烘了多少小时”作为完成依据。

### Q6 炉体外表面温升指标如何转成可验收条件

当前边界：

- 2018 两用型项目技术方案技术参数表第 17 项载明：炉壁温升 `≤40℃+环境温度（热桥除外）`；
- 结合正文语义，规范表达应为：炉子使用温度 800℃、达到稳定态、热桥除外时，方案要求炉体外表面温度不高于环境温度加 40℃，即外表面温升不超过 40 K；
- 当前只能确认这是技术方案中的设计指标，不能证明已写入双方签署的技术协议、客户按此验收或现场实测达到该值。

请唐工确认：

1. 上述规范表达是否准确？“炉壁”应覆盖哪些部位，哪些热桥部位必须明确排除？
2. 若把该指标作为验收依据，测点布置、稳定态判定、环境温度取值、测量仪器、红外发射率和热桥排除规则应如何约定？
3. 是否存在技术协议、竣工资料、测温记录或验收报告，可以证明该指标进入合同约定或被现场验证？
4. 在补齐证据前，页面是否只能写“该项目技术方案采用外表面温升不超过 40 K、热桥除外的设计指标，现场验证方法与结果需另行核对”？

记录：

- 确认结论：技术方案中的设计指标可以转成验收条件，但必须把测点、热桥排除、稳定态、环境温度和测量仪器写进技术协议，不能只保留一个数值。
- 对应协议或验收证据：当前仍未找到双方签署的技术协议、现场测温记录或验收报告，不能写成现场已经达到。
- 测量条件：炉墙、炉顶和炉门测点应预先固定；明确排除炉门框、锚固件贯通处、烧嘴口、热电偶座、炉压取样管和台车边缘等热桥；规定稳定态判定、环境温度取点和测量仪器，使用红外仪器时约定发射率。
- 适用条件：只对应 2018 项目技术方案中炉子使用温度 800℃、达到稳定态、热桥除外的设计边界。
- 不适用条件：不得外推成所有炉型的通用承诺；不得写成客户验收结果或现场实测值。
- 可公开完整句：某项目技术方案采用“炉子使用温度 800℃、达到稳定态、热桥除外时，炉体外表面温升不超过 40 K”的设计指标；如用于验收，还需在技术协议中明确测点、稳定态、环境温度、仪器与热桥排除规则。
