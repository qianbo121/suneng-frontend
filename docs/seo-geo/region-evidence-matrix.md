## 一、发布门槛

地域内容同时满足以下条件时，才可以进入官网独立页面：

1. 地域真实：生产基地、项目所在地或实际服务范围可以被内部资料验证。
2. 业务真实：有明确的客户需求、工件 / 材料、工艺、设备组成或交付边界。
3. 内容独立：不是把同一篇正文替换城市名，页面能回答该项目或地区特有的问题。
4. 表述准确：非当地生产基地不得使用“当地厂家”表述，应使用“项目经验”“服务经验”或“交付案例”。
5. 公开合规：客户名称、Logo、图片、参数和效果数据均符合授权范围。
6. 可被验证：页面有唯一 canonical、结构化数据、站内入口，并进入 sitemap。

任一条件不满足时，内容应并入现有解决方案页、案例组或内部素材库，不新建索引页。

## 三、本轮试点页面定位

### 1. 济宁支重轮热处理生产线案例

- 核心意图：支重轮热处理生产线、工程机械零部件淬火回火线、济宁项目经验。
- 独立证据：明确项目所在地、工件范围和完整工艺链。
- 页面价值：回答设备组成、工艺难点、报价参数、苏能供货边界。
- 禁止扩写：不得补造处理能力、温度、尺寸、节拍、验收结果或客户评价。

### 2. 河南退火固溶段设备案例

- 核心意图：连续退火固溶生产线、不锈钢退洗线退火段、河南项目经验。
- 独立证据：明确项目地域、材料范围和系统设备组成。
- 页面价值：回答温度路径、分段冷却、上下游接口、工程总包协作边界。
- 禁止扩写：不得公开完整技术协议、布置图、材料清单、报价或未经授权的精确参数。

## 四、首轮观察指标

观察周期建议为页面被搜索引擎发现后的 6 至 8 周：

| 层级       | 指标                                                                        | 目的                         |
| ---------- | --------------------------------------------------------------------------- | ---------------------------- |
| 抓取与索引 | sitemap 发现、索引状态、canonical 选择                                      | 验证页面能否被正确发现与收录 |
| 传统搜索   | 地域 + 工件 / 工艺查询的曝光、点击、平均位置                                | 验证是否覆盖真实采购意图     |
| AI 搜索    | Bing AI citations、grounding queries、ChatGPT `utm_source=chatgpt.com` 引荐 | 验证是否成为生成式回答引用源 |
| 站内行为   | 案例页进入产品 / 解决方案页的点击                                           | 验证内容是否帮助继续决策     |
| 商业结果   | 表单、电话、微信中的有效项目线索                                            | 验证流量是否具备采购价值     |

首轮不以“新增页面数量”为目标。若案例页没有形成独立查询、引用或有效线索，应优先调整意图和证据表达，不继续复制地域页面。
