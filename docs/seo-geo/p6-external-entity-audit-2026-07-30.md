# P6 外部实体与渠道现状审计

日期：2026-07-30
范围：只做公开来源核查和修复排序；本轮不代替公司登录外部平台、不发布站外内容、不新增官网页面。

## 一、结论

苏能已经具备可被独立验证的外部证据，但搜索结果中的企业身份并不统一：

- 权威层已有高新技术企业备案、政府项目公示、专利权人记录和地方公开报道；
- 可控经营平台里，智联招聘的企业介绍与官网核心信息基本一致；
- 同时存在未实名认证且已下架的 B2B 商铺、旧公司名称、旧电话、旧域名和相互冲突的企业规模；
- 官网 `Organization / LocalBusiness` 结构化数据当前没有 `sameAs`。在外部身份未完成清理前，不应为了数量挂不稳定或不受控页面。

P6 当前最优动作不是批量发文章，而是先把“江苏苏能工业炉有限公司是谁”统一成一个可被多源交叉验证的实体。

## 三、`sameAs` 与外部证据的使用边界

### 可以进入 `sameAs` 的条件

必须同时满足：

1. 页面主体明确是江苏苏能工业炉有限公司；
2. URL 长期稳定；
3. 公司能够控制内容，或平台已完成权威主体认证；
4. 公司名、统一社会信用代码、地址、电话、官网和主营范围不存在冲突；
5. 已记录平台负责人和最后核对日期。

### 当前不应进入 `sameAs`

- 政府名单 PDF；
- 单个新闻报道；
- 单个专利详情页；
- 单个招聘职位页；
- 未实名认证或已下架商铺；
- 带旧名称、旧电话、旧域名的目录页。

这些页面可以作为外部证据或 `subjectOf` 候选，但不能冒充企业官方同一实体主页。

## 四、执行顺序

### P6-1：先清理冲突

1. 中玻网：认证并更新，或者申请删除；
2. 旧企业目录：更正公司名、电话、官网，或申请删除；
3. 筑招：核实企业规模，无法确认就删除人数；
4. 旧域名：已确认不归公司控制；不访问、不链接、不为其提供任何实体关联，通过平台纠错和权威来源覆盖；
5. 百度知道旧回答：提交“官网链接已失效 / 非当前官网”的纠错，目标是将当前官网统一为 `https://www.jssngyl.cn/`，不在公开文案里反复传播旧域名。

### P6-2：统一可控平台

1. 智联招聘所有职位统一使用标准企业介绍；
2. 企查查 / 爱企查 / 天眼查 / 启信宝等逐一认领或补全；
3. 公众号、视频号、抖音、B2B 等只登记公司能实际控制的主页；
4. 每个平台记录 URL、管理员、核对日期和是否允许公开。

### P6-3：再回官网建立实体连接

当至少有 2 个稳定且已核验的外部企业主页后：

1. 只把合格主页加入 `Organization.sameAs`；
2. 官方/政府/客户新闻以“外部佐证”使用，不混进 `sameAs`；
3. 增加自动测试，禁止旧公司名、旧电话、旧域名重新进入结构化数据；
4. 部署后检查源码、结构化数据和搜索引擎解析结果。

### P6-4：最后做内容分发

先统一实体，再从已过审事实单元制作公众号、文档平台和行业渠道版本。官网先发原始版本，站外发摘要或差异化改写，不复制整页，不让第三方页面反客为主。

## 五、需要公司后续提供

- 中玻网、筑招及企业信用平台的账号归属或可维护人；
- 可公开的公众号 / 视频号 / 抖音 / B2B 企业主页 URL；
- 企业规模是否对外公开及统一口径；
- 各平台更新后的截图、提交日期和审核状态。

在这些信息补齐前，本轮不写 `sameAs`，避免把不稳定页面固化进官网实体。
