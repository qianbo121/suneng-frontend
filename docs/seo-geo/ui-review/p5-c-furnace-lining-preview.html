01 / DIRECT ANSWER

先判断支撑体系，不只看热面坏了多少

炉龄和损坏面积都不能单独决定翻新范围。真正影响决策的是冷面状态、锚固连续性、失效原因、新旧衬接缝条件，以及工况是否发生变化。

一句话结论

损坏不连片、未贯穿冷面、损坏区外锚固完好、失效原因为局部且新旧衬可以可靠衔接时，可考虑局部修复；出现炉顶下沉、冷面异常升温、贯通裂缝等信号时，应扩大拆检，最终范围以停炉检查为准。

02 / INSPECTION SIGNALS

出现这些信号，应扩大检查

信号本身不是脱离现场条件的通用否决项，但说明继续只补热面存在遗漏冷面和锚固风险的可能。

SIGNAL 01

炉顶下沉、鼓包或外凸

优先检查吊挂、锚固件和背衬状态，不能只覆盖表面纤维。

SIGNAL 02

冷面异常升温或变色

排除密封漏热后，应检查贯通裂缝、热桥和保温层缺损。

SIGNAL 03

多次补丁或异常工况

反复修补、超温、进水、气氛侵蚀和工况变化都需要重新核算。

04 / ACCEPTANCE

翻新后应留下哪些验收证据

记录不仅证明施工完成，也为后续判断外壁温升、密封和能耗变化提供可比基线。

STRUCTURE / 结构

冷面、锚固与接缝记录

保留拆除前后照片、冷面钢板状态、锚固检查、新旧衬接缝及穿墙接口记录。

MATERIAL / 材料

合格证与施工参数

某项目方案载明“1140 型、压缩量≥40%”，但牌号含义和适用性仍应结合产品资料与施工方案确认。

DRY-OUT / 烘炉

实测曲线与排湿记录

记录时间—温度曲线、保温时长、排湿口状态、排汽观察、异常处理和环境温湿度，不发布跨材料体系的通用曲线。

SURFACE / 外壁

把温升变成可验收条件

某项目采用 800℃、稳定态、热桥除外时外表面温升不超过 40 K 的设计指标；如用于验收，需约定测点、环境温度、仪器与热桥排除规则。

05 / FAQ

采购方常问

回答给出检查顺序和证据边界，不用没有底稿的通用节能比例代替项目判断。

炉衬坏了一小块，是否只补这一块？

不一定。除损坏面积外，还要检查冷面、锚固、失效原因和新旧衬接缝；发现下沉、异常升温或贯通裂缝时应扩大拆检。

纤维模块压缩量越大越好吗？

不能脱离材料和结构判断。方案中的压缩要求用于补偿高温收缩并维持接缝，但计算基准、安装方向和适用范围应由产品资料与施工设计共同确认。

炉衬翻新后能承诺节能多少吗？

没有同环境、同负载、同工艺和完整统计周期的前后数据，不能给通用比例。应分别记录外壁温度、升温时间、保温功率或燃料消耗及密封状态。

提交炉衬资料，先判断检查边界

建议提供炉型与温度、运行气氛、炉衬结构图、损坏照片、冷面温度、维修与异常历史、计划工况、可用停产窗口和希望复测的指标。
