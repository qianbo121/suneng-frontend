01 / DIRECT ANSWER

先证明设备安全可控，再谈负载复产

原设计能力、旧验收记录和短时启动结果，都不能自动成为搬迁后或长期停产后的新验收结论。

一句话结论

先查清停机原因、资料完整度和设备现状，完成结构、炉衬、能源、电气、测温、联锁与机械检查，再依次做冷态动作、空载升温和负载验证。每一步通过后才能进入下一步，具体检查范围和周期按项目确认。

02 / DO-NOT-START SIGNALS

出现这些情况，不能直接通电或点火

以下信号说明设备状态或安全边界尚未建立，应先补检查和资料，不以一次空转代替系统判断。

SIGNAL 01

停机原因和现状不清

不知道最后工况、故障原因、异常维修或介质残留时，不能直接恢复原启停程序。

SIGNAL 02

图纸、程序或铭牌缺失

控制版本、回路、设备参数和安全逻辑无法核对时，应先测绘、盘点并建立新基线。

SIGNAL 03

搬迁拆解记录不完整

基础、定位、管线、接线和部件编号发生变化后，原安装与验收结论不能直接沿用。

04 / RECOMMISSIONING

分三阶段形成复产证据

每个阶段都要记录条件、结果、偏差和整改，避免用“已开机”替代完整复产验收。

COLD / 冷态

动作、绝缘与联锁检查

核对旋向、行程、限位、阀门、急停、报警、绝缘和失效安全动作，记录缺陷与整改。

NO-LOAD / 空载

按批准条件升温试运行

依据炉衬材料和设备状态确认升温或烘炉要求，检查温区、循环、炉压、机械和异常报警。

LOAD / 负载

固定工件和工艺验证

记录工件、装炉方式、负载、工艺曲线、测量方法和结果；不把空载结果直接作为负载验收结论。

HANDOVER / 交付

形成新的设备基线

归档竣工图、程序与参数备份、报警清单、试验记录、培训资料、备件清单和后续检查计划。

05 / FAQ

采购方常问

回答区分“能启动”“能安全试运行”和“能稳定负载生产”三个不同结论。

停产热处理炉可以直接通电或点火吗？

不建议。应先还原停机原因并检查绝缘、炉衬、密封、能源管线、执行机构、安全联锁和机械状态，再按冷态、空载和负载顺序验证。

工业炉搬迁后，原来的工艺参数还能直接用吗？

只能作为核对起点。基础、找正、管线、接线、循环、炉压和测温条件可能变化，需在新现场重新验证并形成新的设备基线。

旧热处理炉值得再制造吗？

要看结构完整性、安全系统可恢复性、关键备件、能耗和排放边界，以及是否适配新工艺。不能只按购置年份或外观判断。

停产炉重启或搬迁复产需要多久？

应拆分资料恢复、检查、整改、安装、冷态、空载和负载验收阶段，按设备状态、改造范围、现场条件与停产窗口分别确认，不给通用天数。

提交设备现状，先判断检查与复产边界

建议提供炉型与工艺、停机原因和最后工况、设备照片、原图纸与程序、铭牌、维修记录、搬迁拆解记录、能源条件、目标工件和计划复产窗口。
