01 / DIRECT ANSWER

不能只比较电价和气价

应先把工件吸热、炉体散热、烟气与排风损失、待机保温、负荷率、能源单价、增容、安全、排放、维护和停产成本放进同一项目边界。

一句话结论

电改燃、燃改电或余热回收是否值得做，取决于同工况能源基线、生产制度、现场公辅条件和完整改造成本。别的项目的节能比例、吨产品成本和回收期不能直接套用。

02 / PROJECT SIGNALS

先补齐这三类缺口，再谈回报

没有可比基线、没有现场边界或没有稳定利用端时，收益模型看起来精确，实际仍无法验收。

SIGNAL 01

能耗口径不可比

产量、负载、工艺曲线、能源热值、价格和统计周期没有统一。

SIGNAL 02

炉体条件未检查

电改燃会同时牵动炉衬、密封、炉压、排烟、烧嘴接口和控制联锁。

SIGNAL 03

余热没有稳定去向

高温烟气不等于可利用；温度品位、流量、运行时数和利用端必须匹配。

03 / OPTION MATRIX

不同方案分别核对什么

决策应围绕工艺稳定性、基础设施、安全和完整生命周期成本，不用“哪种能源更先进”代替项目判断。

04 / ACCEPTANCE

安全、能耗与排放分别留证

设计目标、接口接收和正式验收是不同层级；结论必须绑定测试条件、记录和责任边界。

FAT / 工厂测试

逻辑和安全动作

记录控制逻辑、阀门动作与严密性、报警触发点、失焰响应，以及断电、断气、断风的安全状态。

SAT / 现场测试

管路和真实工况

验证气密、吹扫、真实失焰、断电、联锁联动和炉压稳定性；FAT 不能替代 SAT。

PROJECT / 项目证据

方案参数不是实际能耗

某项目有效加热区约 13×7.4×4.3 m、700℃、14 个温控区、8820 kW 级燃烧输入；该数字是项目方案边界，不是实际能耗。

ENERGY / 同工况验证

固定分母与统计周期

统一负载、产量、工艺、热值、价格和运行制度后比较；排放是否达标以适用标准和有资质现场检测为准。

05 / FAQ

采购方常问

回答优先给决策输入和验证方法，不给脱离现场的节能率与回收期承诺。

热处理炉电改燃一定更省钱吗？

不一定。需同时比较热效率、负荷率、能源价格、增容、安全、排放、维护和停产成本，并用同工况完整周期数据验证。

两用燃料系统关闭烧嘴供风就安全了吗？

不能。空气侧断风不等于燃料侧隔离；点火许可应由燃料侧切断、实际阀位反馈、模式互锁和吹扫完成共同构成。

烟气温度高就适合做余热回收吗？

还要看流量、运行时数、含尘与腐蚀性、系统压降、维护条件和利用端是否稳定。没有持续利用端，回收设备可能只有名义收益。

提交能源与运行资料，先做边界核算

建议提供工件与装炉量、工艺曲线、产量与运行时数、改造前能耗、能源价格和热值、炉体尺寸、配电/供气条件、烟气参数、排放要求、利用端与停产窗口。
