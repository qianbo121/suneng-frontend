# 唐工工程事实集中访谈清单

目的：用最少的唐工时间，先解锁已发布内容的事实口径，再补费用、验收和风险类非品牌词事实。

## 访谈方式

- 提前把本清单和相关底稿按问题顺序摆好，不在现场临时想问题。
- 经唐工知情同意后全程录音转写。
- 唐工只回答、纠正和确认，不负责整理文字。
- 会后由执行人员拆成事实单元，补入原始证据、适用条件、不适用条件和审核日期。
- 唐工没有明确确认的内容一律记为“待复核”，不得代签或推断。

## 第一组：先补 6 条已发布事实

### F01：3 条 1250 mm 连续退洗线

1. “3 条”和“1250 mm”分别来自哪份合同、技术协议、总图或设备清单？
2. 三条线是否属于同一客户、同一改造项目和同一统计口径？
3. 1250 mm 是机组名义规格、最大带宽还是本项目实际处理宽度？
4. 哪些数量和规格可以公开？对应证据文件编号是什么？

### F02：7,644 万元/年

1. 这是预测值、项目测算值、验收结果还是客户实际财务结果？
2. 基准期和测算期分别是什么时间？
3. 改造前后使用什么能源？各能源价格、税口径和热值口径是什么？
4. 计算包含哪些成本项，不包含哪些成本项？
5. 对应测算表、能耗台账或验收文件编号是什么？
6. 数据由哪个部门或人员确认？是否存在客户确认记录？

### F03：63.7 元/吨

1. 63.7 元/吨的分子由哪些成本差额组成？
2. 分母采用实际有效产量、合格产量还是设计产能？
3. 基准期、测算期、能源价格和含税口径分别是什么？
4. 是否剔除了停机、检修、试生产和异常工况？
5. 完整计算公式和底稿编号是什么？

### F04：120 万吨/年

1. 这是实际有效产量、合格产量、设计产能还是收益测算假设？
2. 对应哪一年或哪一统计周期？
3. 是否为三条线合计？是否与 63.7 元/吨使用同一分母口径？
4. 来源是生产台账、合同能力、客户经营数据还是双方测算假设？
5. 允许公开到什么层级？

### F05：项目周期

1. 30–45 个工作日、4–6 个月、每条线 30–60 天分别指设计、制造、安装、停产还是调试验收？
2. 各阶段起止日期和对应记录是什么？
3. 哪些时间可作为项目经验，哪些只能表述为“按合同和停产窗口确认”？
4. 哪些现场条件会显著延长周期？

### F06：NOx 与排放

1. 项目实际适用的排放标准及版本是什么？
2. 是否有第三方检测或正式验收报告？
3. 检测机构、报告编号、检测日期、测点和工况是什么？
4. 实测值、限值和氧含量折算口径是什么？
5. 若没有可核验报告，页面应保留哪一句范围表达？

## 第二组：补非品牌词缺口

### 费用与回报

1. 工业炉改造费用通常由哪些模块组成？
2. 哪些参数会让预算出现数量级变化？
3. 哪些情况下改造比换新更合适，哪些情况下不建议继续改？
4. 回收期测算最少需要哪些真实输入？
5. 哪些费用经常被采购方漏算？

### 验收与质量

1. FAT、SAT 分别必须检查什么？
2. 温度均匀性、控温精度、产能、能耗、联锁和排放如何定义验收口径？
3. 哪些指标必须在负载状态下测？
4. 测温仪器、校准、测点和保温时间如何记录？
5. 哪些验收结论不能脱离工件、装炉方式和运行制度复用？

### 改造风险

1. 老炉改造最常见的失败原因是什么？
2. 哪些炉体、基础、燃烧、电控或安全问题会直接否决改造？
3. 哪些问题必须停产检查后才能报价？
4. 改造后温度仍不均、能耗未达预期时，优先排查什么？
5. 哪些承诺必须留在合同条件中，不能写成官网通用结论？

## 会后交付

- 每个答案拆为独立事实编号；
- 标注原始证据文件和页码/条款号；
- 填写技术审核人、审核日期、适用条件和不适用条件；
- 客户授权证据单独记录邮件、合同条款或会议纪要编号；
- 通过后再更新页面、真实 `lastmod` 和第二批索引提交。
