# 苏能官网案例分级台账

更新日期：2026-07-29

## 分级口径

- A 级结果案例：具有改造前后同工况对比数字、测量方法、测试条件、仪器与校准信息、验收标准和数据确认人。
- B 级项目经验记录：具有真实客户或脱敏客户、地域、工件、工艺链、设备参数与供货边界，但不公开或不具备完整成果数字证据链。
- A 级候选（测算型）：已经公开项目测算公式、适用边界和部分验收结论，但尚未具备完整 A 级测量证据链；对外不得写成客户财务审计结果或可外推的节能承诺。

## 升级规则

1. 青山案例只有补齐同工况原始数据、测量方法、仪器/校准和数据确认人后，才能升级为完整 A 级结果案例。
2. 济宁或河南案例只有补齐客户书面确认记录、唐工技术复核及获准公开的运行/验收结果后，才能进入 A 级升级审核。
3. 公司已批准的现有页面参数可以继续保留；证据补齐前不得新增精确值、跨页复用或站外分发。
