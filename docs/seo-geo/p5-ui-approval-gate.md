# P5 新页面决策记录

状态：已取消。

2026-07-30，钱波确认不继续工业炉改造投资回收测算页面。原因：当前静态回收期模型只能用于粗筛，尚不足以支撑准确的项目投资判断。

本轮 UI 审核稿撤销，不进入正式施工。未创建官网路由、未加入 sitemap、未部署、未提交索引。

## 当前禁止

- 不创建 P5 新路由；
- 不编写 P5 页面组件；
- 不加入 sitemap；
- 不添加结构化数据；
- 不提交搜索引擎；
- 不将青山测算数字复用到 P5。

## UI 审核必须包含

1. 1440 px 桌面端完整设计稿；
2. 390 px 手机端完整设计稿；
3. 首屏直接答案、静态公式、输入区、结果区、边界说明和询盘入口；
4. 默认、填写中、计算成功、输入错误、证据不足五种状态；
5. AI 不执行 JavaScript 时仍能读取的静态方法与示例；
6. 事实编号、来源、审核状态、适用条件和不适用条件的展示位置；
7. 不使用尚未通过技术复核和客户书面证据门的事实。

如未来重新评估，必须重新提出 UI 与计算口径方案，不沿用本次已取消的审核稿。
