# braces 3.0.3 项目维护补丁

此补丁修复深层括号模式导致的递归栈溢出，并拒绝会绕过普通节点深度检查的非字符串语法树值。名称和版本仍为 braces 3.0.3，不能把原始安全审计报告中的公告当作已经自动消失。

- 来源：上游尚未合并的 [提案 #72](https://github.com/micromatch/braces/pull/72)，固定提交 28d440b5dd449dbf1fe6f3506cf94ecca4d02660。仅回移深度保护及父链接循环检测；未回移主线无关的引号、逗号行为变化。项目另加节点、字符串值和子节点容器类型检查，阻止嵌套或循环数组的隐式转换/展平溢出。
- 行为：花括号与圆括号的合计嵌套硬上限为100，可指定更低上限；非有限值或更高设置不能关闭硬上限。字符串解析超过上限抛 SyntaxError；外部语法树递归超过上限或父链接循环抛 RangeError；非字符串值、非法节点和子节点容器抛 TypeError。合法解析结果和原3.0.3输出保持一致；超过100层的合法复杂模式现在也会被拒绝。不主张修复任意带执行型访问器的对象或所有其它资源耗尽问题。
- 验证：根 package.json 的 pnpm.patchedDependencies 正式绑定此精确版本，根 pnpm-lock.yaml 固定真实生成的补丁记录。直接运行 `node frontend/scripts/braces-check.mjs --json`，或 `pnpm --dir frontend braces:check`。脚本即时检查全部实际安装实例、8个运行文件摘要、各消费者真实模块解析以及63项防护和89项兼容检查，任何缺失、未补丁实例、摘要变化、超时或回归失败都非零退出。原审计和条件处理由独立门槛保留；本脚本不发送外部请求、不忽略安全公告。
