It can establish proposed equipment quantities but cannot replace workpiece process documentation. ## An optional crane does not make transfer arrangements optional

The source allows the crane option to be omitted if the customer's workshop already has an overhead crane. Procurement must therefore check crane coverage, combined part-and-basket weight, lift height and clearances with furnace lids open. Only after these interfaces are workable can omission be assessed. The existence of a crane alone does not establish compatibility.

The preheating working zone, salt-bath crucibles and rectangular tanks are not described using the same cross-sectional geometry. If one basket is intended for all stations, compare each station's effective space, opening and lifting points individually. A rectangular washer's length and width do not establish the basket envelope that fits a circular crucible. Basket and lifting-fixture drawings are not finalised in this draft.

## Machine controls, reserved data connections and automatic line operation differ

The general description specifies distributed controls and reserved communication interfaces, while the later control-configuration table gives the oiling tank no independent electrical control cabinet. It is therefore inaccurate to claim that all five machines have identical temperature control, recording and network functions. Confirm, for each machine, what is measured and stored, which operations are performed locally and which signals go to the workshop system.

A reserved interface provides a basis for later integration; it does not establish completed whole-line monitoring or production-management integration. Movement between stations also requires agreement on batch identity, record matching and responsibility for transfer operations. Separate curves on individual machines are insufficient if they cannot be associated with the same basket of parts.

## List site utilities and unresolved configurations together

Installation terms allocate foundations, power, earthing, extraction and compressed-air interfaces to the buyer, with equipment installation and commissioning assigned to the seller. Extraction connections for salt-bath and oiling operations also need inclusion in the site interface list. This article retains equipment composition and handover relationships without treating suggested material substitutions, process effects or energy savings in the discussion draft as confirmed facts.
