Two Suneng proposals for the same project cover external heating of an impregnation vessel and internal heating of a baking vessel respectively. For equipment following programmed heating and cooling curves, procurement should confirm more than maximum temperature: where the curve is controlled, what load is used for testing and which curve version forms the agreed reference all matter.

## Mark furnace control temperature and vessel-internal temperature separately

The impregnation-vessel process requirements describe heating the internal cavity. The structural description, however, places electric heating tubes around the furnace chamber and uses thermocouples inserted into that chamber for control and recording. These statements concern different locations. An instrument curve following its setpoint first establishes the condition at its measuring position; it does not automatically establish that every location inside the vessel or its contents reaches the required temperature simultaneously.

Before defining the heating equipment, mark the control thermocouples, internal verification points and actual load, and agree which measurement starts the holding-time count. The proposal does not fully map these relationships, and this article does not prescribe a new holding-time start rule.

## Check curves stage by stage, not only total duration

The impregnation proposal contains both a general hourly heating-rate requirement and a staged curve. One ramp in that curve has a rate below the general range. The baking vessel has a different heating/cooling table describing the whole process by cumulative duration. Different applications and curves mean a common test duration does not establish identical production cycles.

Both installation and commissioning clauses require cooperation with a 157-hour simulation test. This defines a proposed seller-support scope but does not prove that both process curves have been achieved. Match curve version, test load, measuring points, permissible deviations and recording files individually. Differences in rates and durations should be reconciled before becoming acceptance criteria.

## Allocate the shell, heating and controls separately

The proposals list lining, heating elements, controls, installation and commissioning, while the shell item includes a buyer-fabricated option. Identify who fabricates the shell, who supplies heating and insulation structures, and who completes installation and temperature-measurement interfaces. A general closing statement that design, manufacture, installation and commissioning are included cannot be used to treat every shell option as seller-supplied.

This record is useful when preparing a heating retrofit for existing vessels. Start with vessel construction, required measuring locations and the complete temperature curve, then review heater and test interfaces. This page retains the historical proposal scope. Changes in later configuration schedules and editable acceptance forms require final configuration documents and matching test records; filenames alone do not establish completed performance acceptance.
